## Notes

The ␣ symbol denotes spaces.

**Intended cheat code** is what the developers wanted you to input to activate the cheat code. For a long time, these codes remained a mystery: back in 2005, a user on GTAForums named edisoncarter as well as some other users [attempted](https://gtaforums.com/topic/194192-pc-cheats/) to find these intended codes. However, most of those were still missing since the dictionary attack they used was flawed: First, it used a dictionary taken from the american.gxt file of the game, as opposed to something better such as the official Scrabble dictionary. Not only that, they didn't consider the possibility that the intended cheat codes can be longer than five words and range anywhere between 6-24 characters. Eventually, the community just gave up after failing to find a lot of them and moved on with their lives. It wasn't until almost 10 years later that all the intended cheat codes were found, thanks to the release of the Android version of GTA SA, where a GTAForums user named [Alexander Blade](https://gtaforums.com/topic/194199-documenting-gta-sa-memory-addresses/?do=findComment&comment=1067260022) found a file that contains them there.

**Shortest codes** are the codes that contain the least amount of characters possible. This is split into two:

- The first one is the shortest code with 
  **combinations of A-Z, 0-9, and spacebar**. This should work on any keyboard layout.
- The other one is the shortest code with 
  **combinations of A-Z, 0-9, spacebar, *and* symbols found in US QWERTY keyboards**, excluding those that require holding the Shift key (because those don't work).
  
 With this combination, it appears that all the cheat codes except for the sandstorm weather cheat can hit 6 characters long, further improving the length, but be aware that oftentimes this only works with US QWERTY keyboards due to the placements of the keys, and while these codes might be much shorter than the other combos, it doesn't necessarily mean that you can type it faster. Some of these symbols can be difficult to reach and/or memorize.

I've managed to download edisoncarter's cheat codes dumps he published on his site back then using Wayback Machine. You can find them here:

- [Two-word cheats dump](files/2wordcheatsdump.txt)
- [Three-word cheats dump, sorted by length](files/3wordcheatsdumpbylength.txt)
- [Three-word cheats dump, sorted by cheat index number](files/3wordcheatsdumpsorted.txt)
- [Four-word cheats dump, 13 letters only](files/4words13letters.txt)
- [Nine-letter cheats dump](files/9lettercheatsdump.txt)

It's highly recommended to not save the game after using cheats, as some of them, such as the riot cheat code, can't be disabled and can cause severe glitches such as the infamous "Madd Dogg glitch". However, some of them, such as weapon, health, wanted level, and spawn vehicle cheat codes appear to have no side effects to the save file, so those are safe to use.

# PS2 (and possibly Xbox) alternative cheat codes

I also found out that the cheat code finder also works for PS2 cheat codes. It uses the exact same hashing method as the PC version, and the PS2 buttons are simulated using 1234-UDLR-TSCX, in which 1234 is L1, L2, R1, R2; UDLR is up, down, left, right; and TSCX is triangle, square, circle, X. It does cause a bit of a headache though trying to turn those button icons into text forms, so mistakes can be quite common.

How many possible combinations are there in the PS2 version? Well, in 2019, using Tuxxor's cheat code finder, I was able to compile the entire list containing exactly **205,586** button combos, with an average of 2,259 combinations per cheat. The PS2 version only stores up to the last 12 button presses in the memory, so cheat codes that are 13 or more presses long won't count, which greatly limits the number of possible combinations. It seems that during the last 7 years, I seem to have forgotten to link this here, so it was buried in my GitHub repo for the longest time (this site uses GitHub pages, so the files have been public all along). You can find it [here](/files/allcheatsPS2.txt).

Finding the intended cheat codes in the PS2 version is much harder because they only consist of button patterns that sometimes aren't that meaningful and noticeable.

If you want to enter these codes in the the Xbox and Xbox 360 version, just replace:- triangle, square, circle, X with Y, X, B, A
- L1, L2, R1, R2 with L Trigger, White, R Trigger, Black (for the OG Xbox version)
- L1, L2, R1, R2 with LB, LT, RB, RT (for the X360 version)

While I haven't tested this myself (I don't have a console, only tested out the PS2 version in PCSX2), it probably should work the same as the PS2 version due to the exact same hashing method.

Cheat codes officially published by Rockstar are those that were carried over from the previous installments (e.g. weapon or health cheats) or disclosed to the media, such as IGN or the Tips and Tricks magazine. This is because Rockstar didn't release all of them, and some had to be figured out via brute-force by the community, and it also means that these brute-forced cheat codes are unlikely to be the intended ones.

In 2005, edisoncarter managed to find a good amount of cheat codes not disclosed by Rockstar by [wiring up a controller](https://www.gtasanandreas.net/news/archive.php?month=1&year=2005) into a PC's parallel port with optocouplers and brute-forcing the hashes with it. [A few months later]([https://www.gtasanandreas.net/news/archive.php?month=5&year=2005](https://gtaforums.com/topic/190495-here-are-the-button-cheats/#entry2807716)), Skiller and CMX found some of the last undiscovered PS2 cheat codes using a cheat code finder that no longer exists today. However, you can still see the output file [here](/files/L1 combinations.txt). Dubbed the "L1 combinations", these are all the possible combinations you can do that end with L1. However, they didn't seem to brute-force cheat codes that end with other button presses, likely due to hardware limitations at the time.
